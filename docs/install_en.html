🏷️ FilaMan Installation

NFC Filament Manager for ESP32

⚠️ Browser Requirement: This installation only works with Google Chrome or Microsoft Edge. Safari and Firefox are not supported.

📋 Prerequisites

  • ESP32 Development Board
  • USB Cable (data cable, not charge-only!)
  • Chrome or Edge Browser
  • Windows: CP210x or CH340 USB drivers (if needed)

🚀 Start Installation

Click the button and connect your ESP32 via USB.

❌ Your browser is not supported. Please use Chrome or Edge. ❌ This page must be accessed via HTTPS.

📝 After Installation:

1 Restart ESP32 - Briefly disconnect the USB connection
2 Configure WiFi - The ESP32 opens a WiFi hotspot "FilaMan-XXXXXX". Connect to it and open http://192.168.4.1
3 Open Web Interface - After WiFi configuration, access FilaMan at http://filaman.local on your network
4 Connect NFC Reader - Connect the PN532 NFC reader and calibrate the scale

🔄 Updates

  • Future updates can be installed directly through the FilaMan web interface (OTA)
  • No USB connection needed for updates!
