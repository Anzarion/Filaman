🔧 Installation & Setup

  • Browser-Installation: Verwenden Sie unseren Web-Flasher für eine einfache Erstinstallation
  • WLAN konfigurieren: Nach dem ersten Start öffnet der ESP32 einen Hotspot "FilaMan-XXXXXX"
  • Web-Interface: Zugriff über http://filaman.local in Ihrem Netzwerk
  • Updates: Zukünftige Updates erfolgen bequem über die Web-Oberfläche (OTA)

📦 Benötigte Hardware

  • ESP32 Development Board (z.B. ESP32 DevKitC)
  • PN532 NFC Reader (I2C oder SPI)
  • HX711 Wägezelle mit Load Cell (optional für Gewichtsmessung)
  • USB-Kabel für die Erstinstallation

📚 Über dieses Projekt

FilaMan ist ein erweiterter Fork von ManuelW77/Filaman mit zahlreichen Verbesserungen für moderne 3D-Drucker und Filament-Management-Systeme. Das Projekt ermöglicht das Auslesen, Bearbeiten und Erstellen von NFC-Tags für 3D-Drucker-Filamente, insbesondere für Bambu Lab Drucker und kompatible Systeme.
