🔧 Installation & Setup

  • Browser Installation: Use our Web Flasher for easy initial installation
  • WiFi Configuration: After first boot, the ESP32 opens a hotspot "FilaMan-XXXXXX"
  • Web Interface: Access via http://filaman.local on your network
  • Updates: Future updates are done conveniently through the web interface (OTA)

📦 Required Hardware

  • ESP32 Development Board (e.g. ESP32 DevKitC)
  • PN532 NFC Reader (I2C or SPI)
  • HX711 Load Cell with Weight Sensor (optional for weight measurement)
  • USB Cable for initial installation

📚 About This Project

FilaMan is an enhanced fork of ManuelW77/Filaman with numerous improvements for modern 3D printers and filament management systems. The project enables reading, editing, and creating NFC tags for 3D printer filaments, especially for Bambu Lab printers and compatible systems.
