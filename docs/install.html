🏷️ FilaMan Installation

NFC Filament Manager für ESP32

⚠️ Browser-Anforderung: Diese Installation funktioniert nur mit Google Chrome oder Microsoft Edge. Safari und Firefox werden nicht unterstützt.

📋 Voraussetzungen

  • ESP32 Development Board
  • USB-Kabel (Daten-Kabel, kein reines Ladekabel!)
  • Chrome oder Edge Browser
  • Windows: CP210x oder CH340 USB-Treiber (falls nötig)

🚀 Installation starten

Klicken Sie auf den Button und verbinden Sie Ihren ESP32 per USB.

❌ Ihr Browser wird nicht unterstützt. Bitte verwenden Sie Chrome oder Edge. ❌ Diese Seite muss über HTTPS aufgerufen werden.

📝 Nach der Installation:

1 ESP32 neu starten - Trennen Sie kurz die USB-Verbindung
2 WLAN konfigurieren - Der ESP32 öffnet einen WiFi-Hotspot "FilaMan-XXXXXX". Verbinden Sie sich damit und öffnen Sie http://192.168.4.1
3 Web-Interface öffnen - Nach der WLAN-Konfiguration erreichen Sie FilaMan unter http://filaman.local in Ihrem Netzwerk
4 NFC-Reader anschließen - Verbinden Sie den PN532 NFC-Reader und kalibrieren Sie die Waage

🔄 Updates

  • Zukünftige Updates können direkt über die FilaMan Web-Oberfläche eingespielt werden (OTA)
  • Keine USB-Verbindung mehr nötig für Updates!
